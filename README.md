# מַעְבֶּדֶת הֶחָלָל שֶׁלִּי · My Space Lab

אפליקציית לימוד ליהלי (כיתה ה') לקראת המבחן במדעים ב‑22.10.2026: מבנה היקום, מערכת השמש, יום ולילה, שנה, חודש ולוח שנה — עמודים 168–190 בספר "נפלאות המדע".
הכול רץ על המחשב בבית: בלי ענן, בלי חשבון, בלי בינה מלאכותית. מה שיהלי מקליד לא יוצא מהמכשיר.

## איפה פותחים

| מה | כתובת |
|---|---|
| הגרסה של יהלי — במחשב | http://localhost:8090 |
| הגרסה של יהלי — בטאבלט (אותה רשת Wi‑Fi) | `http://<כתובת המחשב>:8090` — הפקודה `npm run prod:status` מציגה אותה (כרגע 192.168.1.15) |

ההתקדמות נשמרת **בדפדפן של כל מכשיר בנפרד** (המחשב והטאבלט לא משתפים). לגבות ולהעביר: "אזור הורים" ← Backup.

## הפעלה

```
npm run prod:start     # מפעיל את הגרסה של יהלי (גם אחרי הפעלה מחדש של המחשב)
npm run prod:status    # מה רץ, כתובות למחשב ולטאבלט, מתי היה שימוש אחרון
npm run prod:stop
```

- **שהמחשב לא יירדם** בזמן שיהלי לומד בטאבלט: הגדרות ← מערכת ← הפעלה ושינה ← "שינה: אף פעם" (בחשמל).
- **טאבלט לא מתחבר?** הרשת ב‑Windows צריכה להיות "פרטית" ולא "ציבורית", ופורט 8090 פתוח. פעם אחת, ב‑PowerShell כמנהל:

```
Set-NetConnectionProfile -InterfaceAlias "Wi-Fi 2" -NetworkCategory Private
New-NetFirewallRule -DisplayName "Yahli Space Lab 8090" -Direction Inbound -Protocol TCP -LocalPort 8090 -Profile Private -Action Allow
```

## עדכון גרסה — בטוח, ורק כשיהלי בהפסקה

1. `npm run candidate` — בונה גרסה חדשה ובודק אותה (לא נוגע בגרסה של יהלי).
2. `npm run candidate:preview -- <מזהה>` — לנסות אותה ב‑8091 (התקדמות נפרדת).
3. `npm run release:promote -- <מזהה>` — מעביר ליהלי. **מסרב** אם היה שימוש ב‑20 הדקות האחרונות.
4. אם משהו לא טוב: `npm run release:rollback` — חוזרים לגרסה הקודמת.

- `npm run release:list` — כל הגרסאות. נשמרות תמיד הגרסה הפעילה והקודמת.
- ההתקדמות **לא נמחקת** בעדכון. מאז 17.10 ההתקדמות בגרסה 2 של הנתונים ("המילים שלי"); חזרה לגרסה ישנה יותר תפתח את ההתקדמות **לקריאה בלבד** (`--accept-readonly`), כדי לא לדרוס אותה.
- טאב פתוח נשאר בגרסה הקודמת עד שמרעננים אותו.

## אזור הורים (כפתור "Parent area · לַהוֹרִים" בתחתית המסך הראשי)

- **תשובות שמחכות לבדיקה** — תשובות בעברית שיהלי אמר או כתב. רק אישור שלך נחשב "עברית מאושרת".
- **רעיונות לעבור עליהם יחד** — איפה טעה או נעזר, עם עמודים בספר.
- **שאלות תרגול ליום 5** (21.10) — בעל‑פה ועל דף, עם מחוון ותשובה לדוגמה.
- **המילים שלי** — מילים שיהלי שמר ולא הבין; למילים שאינן במילון של קיפ אפשר לכתוב פירוש.
- **גיבוי** — ייצוא לקובץ וייבוא (ייבוא רק מוסיף, לא מוחק).
- **להתחיל מחדש** — מקלידים `START FRESH`. קודם נשמר עותק שלא נמחק לעולם, ואפשר לשחזר כל עותק.

## בדיקה ראשונה עם יהלי (10–15 דקות)

1. פותחים בטאבלט את כתובת הגרסה של יהלי, ומקלידים את השם בלשונית "Add your name".
2. משימה 01: עוברים יחד שלב אחד (חקירה) — לוחצים 🔊 הַקְרָאָה ובודקים שיש קול בעברית.
3. יהלי שואל את קיפ (החייזר בפינה) מילה, למשל "תצפית", ושומר אותה ב"המילים שלי".
4. עונה על שאלה אחת לא נכון בכוונה — רואים רמז, הסבר אחר ודוגמה.
5. נכנסים לאזור ההורים ובודקים שהתשובה מופיעה. מייצאים גיבוי ראשון.
